CoREX Project

Global/Comprehensive Representative Excellence (CoREX)

Project Overview

The CoREX project is a large-scale initiative aiming to collect and standardize background data on political elites across 52 countries. Understanding who governs is crucial for analyzing representation and policy outcomes.

As part of this project, I developed the technical infrastructure for data collection, including smart scrapers and an AI-assisted annotation platform to process thousands of political profiles efficiently.

  • 52 Countries covered
  • AI-Assisted Data Collection
  • Tech Stack: Python, Flask, BERT

Key Features & Contributions

Smart Scrapers

Developed robust web scrapers to gather structured data from diverse parliamentary websites and government portals across the globe.

Annotation Platform

Built a Flask-based web interface allowing researchers to verify and annotate scraped data, integrating BERT models to suggest likely values.

Data Standardization

Designed a unified schema to harmonize disparate data sources, enabling cross-national comparative analysis.

GPT Data Augmentation

Experimented with GPT-4 to fill in missing biographical details from unstructured text sources.
